# PC Insight · Computer Use 日常功能测试清单

本文件交给具备电脑操作能力（computer use）的测试代理使用。代理按顺序操作 Windows 桌面上的 PC Insight，逐项判断“通过 / 失败 / 阻塞 / 跳过”，并按第 2 节格式记录证据。

- **适用版本**：`release\PCInsight.exe`（0.4.0，“工作观察手札”新界面）。
- **两条测试轨道**：
  - **主轨道 A**：真实 Windows 桌面版，覆盖日常使用的全部功能。
  - **附录轨道 B**：浏览器演示版，用合成数据和故障注入测试错误、压力等难以在真机制造的状态。
- **预计用时**：主轨道约 90–120 分钟。其中有几段需要等待 3–5 分钟，用来产生真实记录。

---

## 0. 测试代理必须遵守的规则

1. **只制造测试数据。** 所有测试用的项目、规则、任务名称都以 `CU测试` 开头。不要打开私人邮件、聊天记录、网银、密码管理器等含个人信息的窗口，因为它们的标题会被记录下来。
2. **配对码不得外泄。** 不要把浏览器配对码粘贴到报告、截图说明或任何网页里。只验证“已复制”的反馈，以及扩展能否连接。
3. **不改系统设置。** 唯一例外是测试 T15 的“开机启动”，测完必须恢复为测试前的状态。
4. **判断以界面实际显示为准。** 时间允许误差：采样精度 1–5 秒，时长类数字允许 ±1 分钟。不要凭推测判通过。
5. **每项都要有证据。** 失败或有疑问的项目，截一张包含完整窗口的截图，写明看到的文字和数字。
6. **出现以下情况立即停止，并报告为“阻塞”：**
   - 程序崩溃；
   - 界面整页空白超过 10 秒；
   - 弹出的提示要求输入密码或修改系统安全设置。
7. 测试中不要删除 `%APPDATA%\local.pc-insight.desktop.cu-backup` 这个备份目录。

| 编号 | 操作 | 通过标准 |
| --- | --- | --- |

## 2. 结果记录格式

测试代理最终输出一张表，每个测试编号一行：

```text
| 编号 | 结果 | 证据（看到的文字/数字/截图名） | 备注 |
| T03.2 | 通过 | 状态行显示“正在记录 · 此刻：Notepad.exe” | — |
| T07.4 | 失败 | 保存后列表仍显示“待确认”，截图 T07-4.png | 刷新后才变化 |
```

最后汇总：通过 N 项、失败 N 项、阻塞 N 项、跳过 N 项，并列出全部失败项。

## 附录 B：判定口径速查（判断“专注 / 分心 / 待确认”是否正确）

| 情况 | 应显示的工作状态 |
| --- | --- |
| 有当前目标，应用名、标题或域名包含该项目任一关键词（不区分大小写） | 专注（分类依据“匹配当前目标关键词”） |
| 命中自定义规则（新规则优先于关键词） | 按规则设定；分类依据“自定义规则” |
| 有当前目标，且活动属于娱乐类（如 bilibili、steam、douyin、netflix）或沟通类（如 微信、wechat、discord、slack），而项目类别不同 | 与目标无关：连续 ≥ 3 分钟为**分心**，15 秒–3 分钟为**短暂打断**，< 15 秒为**短切换** |
| 有当前目标，但既不匹配关键词也不属于上述两类（如计算器、记事本打开无关文件） | **待确认** |
| 没有当前目标 | 一律**待确认**（从不算专注或分心） |
| 无操作超过离开阈值，或点了“休息一下” | 离开 / 休息 |
| 人工纠正过的片段 | 按纠正结果；分类依据“人工纠正” |

其他固定口径：
- 电脑活动只统计主注意力轨；辅助窗口和后台任务都不计入人的时间。
- 深度工作是同一天内连续专注 ≥ 25 分钟的时段之和；跨午夜的专注按各日分别判断。
