# PC Insight 0.4.0 · Windows x64

双击 PCInsight.exe。需要 Windows 的 WebView2 运行时。

首次使用：创建项目 → 填写标题/域名关键词 → 选为当前目标 → 开始记录。

默认优先读取本机 ActivityWatch 的窗口和 AFK 数据；未运行 ActivityWatch 时自动使用 Windows 原生采集。采集来源可在设置切换。可单独从 ActivityWatch 官网安装并运行它。

Chrome / Edge 的域名支持：在扩展管理页启用开发者模式，加载本压缩包的 browser-extension 文件夹。将桌面版设置中的配对码粘贴到扩展弹窗。

关闭主窗口会隐藏到系统托盘；托盘菜单可以退出。默认暂停记录，且不开启系统自启动。后台任务需手动开始/完成，不会把 Codex 窗口开着误算为任务运行。

数据保存在你的用户应用数据目录中，设置中会显示完整路径。所有记录仅在本地，不含云端分析或账户服务。PC Insight 的暂停与排除不会改变 ActivityWatch 自己的记录。

这是首版：可用的核心时间记录、目标分类、并行工作、日/七日报告；浏览器扩展安装联调、多日稳定性及高级分析仍需迭代。
