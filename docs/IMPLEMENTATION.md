## 与原文相比的明确取舍

1. ActivityWatch 是优先数据源，而非硬依赖；未安装/停止时原生采集提供可用性。
2. 不以桌面进程是否存在推断 AI 任务是否在运行。任务自动识别待接到可靠事件源后再做。
3. sessions / daily_stats / weekly_stats 首版实时派生，不维护容易与规则修改冲突的重复统计缓存。
4. 默认暂停采集，用户明确点击开始；软件可选开机启动，但重新启动仍暂停。
5. 数据库不预填演示活动。浏览器演示与真实桌面完全分开。

先连续使用 2–3 天，检查窗口标题、AFK、ActivityWatch 来源和时间线准确性；再决定 V0.3 的任务事件接入方式。累计一周真实数据后增加高级分析，最后再做 V0.5。
